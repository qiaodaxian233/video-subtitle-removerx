# 豆包 AI 视频水印去除指南

针对字节跳动豆包 AI 生成视频的 "豆包AI生成" 水印去除。

## 水印特征

豆包生成的视频水印会**在两个角之间交替出现**（反去除设计）：

- 一段时间在右下角
- 然后跳到左上角
- 再跳回右下角
- 通常 3-4 秒切换一次

**应对方法**：把两个角同时作为去除区域传给 VSR。水印在 BR 时，TL 区域是干净的；反之亦然。STTN / ProPainter 会从这些"干净帧"取参考像素填补。

## ⚠️ 不同视频水印宽度会变

豆包水印有两种宽度：

- **"豆包AI"** (3 字) — 短宽度
- **"豆包AI生成"** (5 字) — 长宽度（多数视频是这个）

直接套用别人的坐标可能盖不住，**先用 measure 脚本测自己视频的精确坐标**（见下方）。

## 1280×720 横屏视频坐标（"豆包AI生成"5字水印实测）

| 区域 | YMIN | YMAX | XMIN | XMAX | 尺寸 |
| --- | --- | --- | --- | --- | --- |
| 左上 (TL) | 0 | 100 | 0 | 260 | 100 × 260 |
| 右下 (BR) | 620 | 700 | 1030 | 1280 | 80 × 250 |

## CLI 命令

```bash
# ProPainter（推荐：质量最好，RTX 3080 Ti 12G 跑 10 秒视频 1.5-3 分钟）
python backend/main.py \
  -i 输入视频.mp4 \
  -o 输出视频.mp4 \
  -c 0 100 0 260 \
  -c 620 700 1030 1280 \
  --inpaint-mode propainter

# STTN（速度快 5-10×，质量稍差，批量场景用）
python backend/main.py \
  -i 输入视频.mp4 \
  -o 输出视频.mp4 \
  -c 0 100 0 260 \
  -c 620 700 1030 1280 \
  --inpaint-mode sttn-auto
```

## 批量处理

### Windows (推荐)

```cmd
tools\remove_doubao_watermark.bat <输入文件夹> [输出文件夹] [模式]
```

例子：

```cmd
REM 默认 ProPainter 高质量
tools\remove_doubao_watermark.bat E:\短剧素材 E:\短剧已清理

REM 切换到 STTN 快速模式
tools\remove_doubao_watermark.bat E:\短剧素材 E:\短剧已清理 sttn-auto
```

脚本会自动激活项目自带的 `videoEnv` 虚拟环境。

### Linux / Mac / WSL

```bash
./tools/remove_doubao_watermark.sh <输入文件夹> [输出文件夹] [模式]
```

两个脚本扫描输入文件夹下所有 mp4，输出到指定文件夹，自动跳过已处理的视频。

## 自动测量水印坐标（针对你的视频）

如果默认坐标盖不住你的水印，用测量脚本：

```bash
python tools/measure_doubao_watermark_box.py 你的视频.mp4
```

输出：

1. **热力图 PNG**（同视频目录，`<视频名>_heatmap.png`）——红/黄色亮块就是水印位置，对照网格读 YMIN/YMAX/XMIN/XMAX
2. **自动建议的 box 坐标**（仅供参考，可能误检背景里的高对比物体）
3. **一键复制的 CLI 参数**

**正确流程**：

1. 跑脚本，打开输出的 heatmap.png
2. 看清红色亮块在哪几个角（一般是 TL + BR）
3. 如果自动建议正确，直接复制 `-c YMIN YMAX XMIN XMAX` 段
4. 如果自动建议误检（比如把背景里的人物轮廓也圈了），自己照网格读坐标
5. 把坐标替换到批处理脚本里的 `TL_COORDS` / `BR_COORDS`

## 算法选择

| 算法 | 速度 | 显存 (12G 卡可调) | 效果 | 适用场景 |
| --- | --- | --- | --- | --- |
| **STTN** | 快（1080p 接近实时） | ~3 GB | 真人/AI 视频效果好 | 批量、追求速度 |
| **LAMA** | 中 | ~6 GB | 单帧画面好，视频易闪烁 | 不推荐用于视频 |
| **ProPainter** | 慢（5-10× STTN） | 默认 ~6G (MaxLoadNum=20)，调高更吃显存 | **最好**，强运动场景突出 | 单条视频追求质量 |

短剧场景默认用 ProPainter——背景多是 AI 生成的强动态场景（爆炸、特效、推拉镜头），ProPainter 比 STTN 明显好。

## ProPainter 显存调节

`backend/config.py` 里：

```python
propainterMaxLoadNum = RangeConfigItem("ProPainter", "MaxLoadNum", 20, RangeValidator(1, 300))
```

显存对照（1080p 估算）：

| 显存 | 推荐 MaxLoadNum |
| --- | --- |
| 6 GB | 12-15 |
| 8 GB | 20 (默认) |
| 12 GB | 40 |
| 16 GB | 60 |
| 24 GB | 80-100 |

调高后处理速度也会快（每批处理更多帧）。如果跑出来报 CUDA OOM 就调低。

## 其他分辨率

竖屏短剧（1080×1920 或 720×1280）水印位置和大小都不一样：

1. 跑 `python tools/measure_doubao_watermark_box.py 竖屏视频.mp4`
2. 看 heatmap.png 读出新坐标
3. 替换到批处理脚本
