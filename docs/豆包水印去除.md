# 豆包 AI 视频水印去除指南

针对字节跳动豆包 AI 生成视频的 "豆包AI生成" 水印去除。

## 水印特征

豆包生成的视频水印会**在两个角之间交替出现**（反去除设计）：

- 一段时间在右下角
- 然后跳到左上角
- 再跳回右下角
- 通常 4 秒切换一次

**应对方法**：把两个角同时作为去除区域传给 VSR。水印在 BR 时，TL 区域是干净的；反之亦然。STTN / ProPainter 会从这些"干净帧"取参考像素填补。

## 1280×720 横屏视频坐标（已实测）

| 区域 | YMIN | YMAX | XMIN | XMAX | 尺寸 |
| --- | --- | --- | --- | --- | --- |
| 左上 (TL) | 5 | 105 | 30 | 290 | 100 × 260 |
| 右下 (BR) | 605 | 720 | 980 | 1240 | 115 × 260 |

## CLI 命令

```bash
# STTN（推荐：速度快，质量好，8GB 显存即可）
python backend/main.py \
  -i 输入视频.mp4 \
  -o 输出视频.mp4 \
  -c 5 105 30 290 \
  -c 605 720 980 1240 \
  --inpaint-mode sttn-auto

# ProPainter（质量最高，但慢 5-10×，需 15GB+ 显存或调小 MaxLoadNum）
python backend/main.py \
  -i 输入视频.mp4 \
  -o 输出视频.mp4 \
  -c 5 105 30 290 \
  -c 605 720 980 1240 \
  --inpaint-mode propainter
```

## 批量处理

`tools/remove_doubao_watermark.sh` 是批量脚本，用法：

```bash
./tools/remove_doubao_watermark.sh /输入文件夹 /输出文件夹
```

会扫描输入文件夹下所有 mp4，全部用上述坐标 + STTN 处理，输出到指定文件夹。

## 算法选择

| 算法 | 速度 | 显存 | 效果 | 适用场景 |
| --- | --- | --- | --- | --- |
| **STTN** | 快（1080p 接近实时） | 8GB | 真人/AI 视频效果好 | 批量、追求速度 |
| **LAMA** | 中 | 6GB | 单帧画面好，视频易闪烁 | 不推荐用于视频 |
| **ProPainter** | 慢（5-10× STTN） | 15-25GB | 最好，强运动场景突出 | 单条视频追求质量 |

## 其他分辨率

竖屏短剧（1080×1920 或 720×1280）水印位置和大小都不一样，需要重新测坐标。建议方法：

1. 用 ffmpeg 抽几帧水印明显的图：`ffmpeg -ss 1 -i 输入.mp4 -frames:v 1 frame.png`
2. 用任意图片软件（Photoshop / GIMP / 在线工具）的标尺工具量水印矩形的像素坐标
3. 套上面的命令模板

## ProPainter 显存调节

如果显存不够爆 OOM，改 `backend/config.py`：

```python
# 默认值已经从 70 降到 20（适配 8GB 显存）
# 显存更大可以调高，效果更好；OOM 就调低
propainterMaxLoadNum = RangeConfigItem("ProPainter", "MaxLoadNum", 20, RangeValidator(1, 300))
```
